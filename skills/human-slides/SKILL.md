# Human Slides (Anti-Slop Presentations & Pitch Decks)

## Anti-Slop Slide Rules
1. **One Insight + One Visual Per Slide**: Never dump 6 equal-weight KPI stat tiles onto a slide (dashboards are for monitoring; slides are for persuading). State one concrete claim in the headline and back it with one focused chart, diagram, or table.
2. **Insight-Led Headlines, Not Topic Labels**: Replace generic titles like `"Market Overview"` or `"Q3 Metrics"` with the actual takeaway (e.g., `"Enterprise retention rose to 94% after onboarding cut setup time in half"`).
3. **No `border-l-4` Callout Boxes or Emoji Bullets**: Use clean typography, whitespace (30%+ open canvas), and alignment instead of stacked colored-border boxes.
4. **Strict 2-Color Discipline**: Lock 1 canvas/neutral family + 1 primary accent hex across the entire deck. Do not let per-card accent bars drift into 5–6 rainbow colors.
5. **No Fabricated Round Numbers**: Never invent placeholder metrics (`+40%`, `10x`, `$1M`). If real data isn't provided, mark `[Data needed: ...]` explicitly so the user fills it in.
6. **Editable Native Charts**: Prefer native/editable chart data or clean SVG/HTML charts over flattened bitmap screenshots when building slide decks.
7. **Humanize All Slide Copy**: Apply `humanize-copy`—ban `"X, not Y"` matched-pair slogans, italic-serif single-word flourishes in headlines, em-dashes (`—`), and filler conclusions.
